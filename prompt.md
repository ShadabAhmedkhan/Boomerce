# 27. Design Direction

The site must feel like a premium modern technology company.

Visual characteristics:

* Clean dark/white combination
* Strong typography
* Large headings
* Generous whitespace
* Premium cards
* Soft gradients
* Subtle borders
* Smooth hover effects
* Modern icons
* Carefully controlled shadows
* Rounded corners
* Minimal but polished animations
* Clear section separation
* Professional SaaS appearance

Avoid:

* Cheap template appearance
* Excessive gradients
* Excessive glassmorphism
* Too many animations
* Huge blocks of text
* Random colors
* Generic stock imagery
* Cluttered layouts

# 35. Important Development Rule

Do not simply copy the existing Boomerce homepage.

Rebuild its information architecture so visitors immediately understand that:

**Boomerce builds its own software products, operates digital businesses, develops custom software, builds e-commerce solutions, and provides digital growth services.**

The three flagship properties should initially be:

1. **StockPro**
2. **EMS**
3. **RenewedDubai**

And the major service pillars should be:

1. **Software Development**
2. **E-Commerce**
3. **SEO**
4. **Digital Marketing**
5. **Automation**

Design and code the website so additional products, businesses, services, industries, and case studies can be added later without redesigning the entire site.

Build the complete production-ready website, not a mockup. Ensure all navigation, mobile menus, forms, CTA links, dropdowns, animations, internal pages, responsiveness, and SEO metadata work correctly.
